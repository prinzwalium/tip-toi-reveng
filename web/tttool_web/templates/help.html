Not available in the web GUI

tttool play is an interactive terminal simulation and has no browser equivalent; run it from a shell inside the container if you need it: docker compose exec tttool-web tttool play /data/<project>/book.yaml.

Text to speech

Instead of recording every sample you can add a speak: section to your YAML file (see text2speech.yaml in the repository) and let tttool synthesize them. The container ships pico2wave, espeak-ng and oggenc for that; generated samples are cached in the project's tts-cache/ directory.
