{{ t("1. Print") }}

  1. {{ t("Print the test page first — one sheet tells you whether your printer can do this at all.") }}
  2. {{ t("Print at 100%.") }} {{ t("Never “fit to page”, “shrink to fit” or “scale”. This is the mistake that makes a perfect looking book do nothing.") }}
  3. {{ t("Use a laser printer. The pen reads black toner; most inkjets do not work.") }}
  4. {{ t("Check that the dashed frame on the test page is complete on all four sides. No printer prints to the very edge of the sheet — usually the last 4 to 5 mm stay white.") }}
  5. {{ t("Measure the printed 50 mm line with a ruler. If it is not 50 mm, the print was scaled — print again.") }}
  6. {{ t("Tap the squares on the test page with the pen. The smallest one that answers is the smallest area you should use.") }}

{{ t("2. Copy onto the pen") }}

  1. {{ t("Plug the pen into the computer with the USB cable and switch it on.") }}
  2. {{ t("It appears as a drive called “tiptoi”.") }}
  3. {{ t("Copy the .gme file into the top level of that drive — not into a folder.") }}
  4. {{ t("Eject the drive safely and unplug the pen.") }}
  5. {{ t("Tap the power-on field on your printed page. The pen says it is loading, and then your book works.") }}

{{ t("When the pen does not play along")}}

{{ t("The pen asks for the power-on field again and again") }}
{{ t("It cannot read the field. Check the print scale (the 50 mm line), print on a laser printer, and keep the field away from dark artwork.") }}
{{ t("Nothing happens anywhere on the page") }}
{{ t("The .gme file is probably not on the pen, or it landed in a folder. It has to sit directly on the drive.") }}
{{ t("The pen says the file does not belong to this product") }}
{{ t("Another book on the pen uses the same book number. Give this book a different number and build it again.") }}
{{ t("Only some areas answer") }}
{{ t("Those areas are probably too small, or the picture under them is too dark. The editor warns about both before you print.") }}
{{ t("The pen stays silent although it was loading") }}
{{ t("Check that the areas have a sound: an area without one is left out of the book.") }}
{{ t("Something at the edge of the sheet is missing") }}
{{ t("That is the printer's own margin, not a mistake in the file: the last few millimetres cannot be printed. Everything this program places keeps 12 mm clear, so if something of yours is cut off, move it further in — an area that reaches into the edge is marked before you print.") }}
{{ t("Cut off, but not shrunk — is that bad?") }}
{{ t("It is the good case: a page that comes out cut off was printed at its true size. A page that fits everything in but reads 48 mm on the 50 mm line was scaled down, and no pen will read it.") }}
