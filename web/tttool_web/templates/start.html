{{ t("Your first book") }}

{{ t("Four steps from an empty page to a book the pen reads out loud. Nothing here needs any technical knowledge.") }}

{{ t("1. Start a book") }}

  1. {{ t("On the start page, choose what you want to make — a sound book is the easiest.") }}
  2. {{ t("Give it a name and pick the paper you will print on. Both can be changed later.") }}
  3. {{ t("You land in the editor, with an example page that already talks. Try it out; then replace it with your own.") }}

{{ t("2. Your picture, your areas") }}

  1. {{ t("“Choose picture …” uploads a photo or scan of your page. It is fitted onto the paper, never cut off.") }}
  2. {{ t("Drag a rectangle onto every thing that should make a sound. For round or odd shapes use “Free shape” and click the corners.") }}
  3. {{ t("Areas should be at least the size of a postage stamp — smaller ones are hard for the pen to hit. The editor says so before you print.") }}
  4. {{ t("Without a mouse: the tab key jumps from area to area, the arrow keys move the selected one, + and − change its size. Hold shift to go in bigger steps.") }}

{{ t("3. Give each area a sound") }}

  1. {{ t("Click an area, then “Choose sound …”. A sound can be used by as many areas as you like.") }}
  2. {{ t("Record it with the microphone, let the computer speak a sentence, or upload a file — whatever you have.") }}
  3. {{ t("An area can do more than play: one of several at random, one after the other, or right and wrong in a quiz. Pick it under “What happens?”.") }}
  4. {{ t("An area without a sound stays silent and is left out of the book — the editor marks those.") }}

{{ t("4. Print it and put it on the pen") }}

  1. {{ t("“Make book” produces two things: a PDF to print and a file for the pen.") }}
  2. {{ t("Print the test page first and check it with a ruler — that one sheet saves a lot of paper.") }}
  3. {{ t("Print your page at 100 % on a laser printer, and copy the .gme file onto the pen.") }}
  4. {{ t("The details are on their own page:") }} {{ t("Onto the pen") }}.

{{ t("Things worth knowing") }}

{{ t("Everything saves itself") }}
{{ t("There is no save button in the editor. Changes are written as you make them; “Saved” next to the book title tells you so. Ctrl+Z undoes, Ctrl+Shift+Z redoes.") }}
{{ t("A book can have several pages") }}
{{ t("Add pages with “+ Page”. They all end up in the same file for the pen, and print as one PDF.") }}
{{ t("Passing a book on, and backups") }}
{{ t("“Pass on” packs one book — pictures, sounds and all — into a single file that someone else can add to their own server with “Add book”. “Back up everything” does the same for every book at once; adding that file back restores all of them.") }}
{{ t("Nothing here can break the pen") }}
{{ t("A file the pen does not like is simply not played. Deleting it from the pen is enough to undo anything.") }}
